# TIP-002: Core UI Components & Hero/Problem Sections

## HEADER
- TIP-ID: TIP-002
- Project: EcoCharge Landing Page
- Module: UI Components & Core Sections
- Depends on: TIP-001
- Priority: P0
- Estimated effort: 30 minutes

## CONTEXT
- Working directory: `src/components/ui/` and `src/components/sections/`
- Key files to create/modify: `Button.tsx`, `HeroSection.tsx`, `ProblemSection.tsx`, `src/app/page.tsx`.

## TASK
1. Create reusable UI Components in `src/components/ui`:
   - `Button.tsx` (Pill shape 50px).
2. Create standard Sections in `src/components/sections`:
   - `HeroSection.tsx` (REQ-001)
   - `ProblemSection.tsx` (REQ-002)
3. Assemble these sections in `src/app/page.tsx` (replacing the showcase preview from TIP-001).

## SPECIFICATIONS

**1. UI Components (`Button.tsx`):**
- Must use `rounded-full` (to achieve the 50px pill shape).
- Primary variant: Background `accent-green` (`#00754A`), text white.
- Hover state: `scale-95` or slightly darken the background to give tactile feedback. No gradients.

**2. Hero Section (`HeroSection.tsx`):**
- Layout: Centered content or Two-column (Desktop-first).
- Background: `bg-canvas` (`#f2f0eb`).
- Headline: *"EcoCharge: Powering the Smart City with Every Step"* (Use `text-house-green`, large bold font, tracking tight).
- Sub-headline: *"Harnessing piezoelectric technology to convert foot traffic into clean energy. Aiming for Net Zero."* (Use `text-house-green/80`).
- CTA: Include the Primary `Button` with text *"Download Pitch Deck"*.

**3. Problem Section (`ProblemSection.tsx`):**
- Purpose: Highlight urban energy waste vs EcoCharge solution.
- Background: Use a contrasting color-block, e.g., `bg-house-green` (`#1E3932`) with text white/canvas, OR use `bg-surface` (`#edebe9`) with house-green text. Ensure high contrast.
- Content: Short copy emphasizing the burden on the electrical grid and how footsteps are wasted energy.

## ACCEPTANCE CRITERIA
Given: The `Button.tsx` component
When: Rendered on the page
Then: It must be fully rounded (pill shape) and use the correct Accent Green color without any gradients.

Given: The `HeroSection`
When: Viewed on a Desktop viewport
Then: The headline must be prominent, perfectly legible against the cream canvas, and contain the "Download Pitch Deck" CTA.

Given: The `page.tsx` route
When: Navigating to `/`
Then: The user should see the Hero Section followed immediately by the Problem Section.

## CONSTRAINTS
- **DO NOT** implement `TechSection.tsx` (the Framer Motion scroll reveal) in this TIP. That is reserved for TIP-003.
- Use simple, semantic HTML tags (sections, h1, h2, p).
- Stick strictly to the colors defined in Tailwind v4 `@theme` from TIP-001.
