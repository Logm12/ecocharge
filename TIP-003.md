# TIP-003: The Heavy Lifter — Tech Section & Scroll Reveal Animation

## HEADER
- TIP-ID: TIP-003
- Project: EcoCharge Landing Page
- Module: TechSection & Animation
- Depends on: TIP-001, TIP-002
- Priority: P0
- Estimated effort: 45 - 60 minutes

## CONTEXT
- Working directory: `src/components/sections/`
- Key files to create/modify: `TechSection.tsx`, `src/app/page.tsx`.
- Core Library: `framer-motion` (`useScroll`, `useTransform`, `motion`).

## TASK
1. Create `TechSection.tsx` as a Client Component (`"use client"`).
2. Implement a sticky scroll-reveal animation that visually deconstructs the 3 layers of the EcoCharge pad.
3. Integrate `TechSection` into `src/app/page.tsx` directly below `ProblemSection`.

## SPECIFICATIONS

**1. Layout & Scroll Mechanism:**
- The section should have a tall height (e.g., `h-[300vh]`) to allow for a long scroll duration.
- Use a `sticky top-0 h-screen` container inside it to pin the visual area while the user scrolls.

**2. The 3 Layers (Visuals):**
You must visually represent 3 distinct layers (can use stylized CSS `div` shapes, isometric transforms, or SVGs):
- **Top Layer (Polycarbonate):** Translucent, durable surface.
- **Middle Layer (Piezoelectric Discs):** The core technology (represent with circular patterns/nodes).
- **Bottom Layer (Aluminum Base):** Solid structural support.

**3. Animation Choreography (Framer Motion):**
- Map the `scrollYProgress` of the section to the `y` or `z` transform of the 3 layers.
- **Start (0% scroll):** All 3 layers are stacked together looking like a single flat pad.
- **Mid (50% scroll):** The layers "explode" or separate vertically, revealing the inside. Text explaining the Piezoelectric effect fades in.
- **End (100% scroll):** Layers fully separated with clear labels for each layer.

**4. Typography & Styling:**
- Background: `bg-surface` (`#edebe9`) to contrast with the previous section.
- Text: Use `house-green` (`#1E3932`). Keep explanations concise and impactful.

## ACCEPTANCE CRITERIA
Given: The `TechSection.tsx` component mounted on the page
When: The user scrolls down into the section
Then: The container must stick to the screen while the scroll action drives the animation of the layers separating.

Given: The 3 layers in the animation
When: The animation reaches its peak (separated state)
Then: The user must clearly see 3 distinct layers (Polycarbonate, Piezoelectric, Aluminum) with accompanying descriptive text.

Given: Framer Motion implementation
When: Scrolling up and down repeatedly
Then: The animation must be completely smooth and tied strictly to scroll position without jank or infinite loops.

## CONSTRAINTS
- **Desktop-First:** Focus 100% on making this look incredible on Desktop (16:9 ratio). You can stack them statically on mobile if animation is too complex for small screens.
- Do not use complex 3D libraries like Three.js. Stick strictly to 2D transforms (`translateY`, `rotateX`, `scale`) combined with Framer Motion.
