## TASK
1. Initialize a new Next.js project (TypeScript, Tailwind CSS, App Router, ESLint).
2. Install required dependencies: `framer-motion` and `lucide-react`.
3. Configure `tailwind.config.ts` to strictly implement the defined Design System tokens.
4. Clean up Next.js boilerplate CSS in `src/app/globals.css`, keeping only Tailwind directives and applying base global styles.
5. Update `src/app/layout.tsx` to use the `Inter` font (or similar clean sans-serif) with specific tracking, and set the global background color.

## SPECIFICATIONS
**1. Tailwind Configuration (`tailwind.config.ts`):**
Extend the theme to include exact design tokens:
- **Colors**:
  - `canvas`: `#f2f0eb` (Warm cream)
  - `surface`: `#edebe9` (Ceramic off-white)
  - `house-green`: `#1E3932`
  - `brand-green`: `#006241`
  - `accent-green`: `#00754A`
- **Border Radius**:
  - `pill`: `50px`
  - `card`: `12px`
- **Letter Spacing**:
  - `tight-brand`: `-0.01em`

**2. Global Styles (`globals.css`):**
- Remove all default Next.js background gradients and dark mode overrides.
- Apply `@apply bg-canvas text-house-green antialiased tracking-tight-brand;` to the `body` tag.
