# TIP-006: Build Carousel Component & State Logic

## HEADER
- TIP-ID: TIP-006
- Project: EcoCharge Landing Page
- Module: UI Components
- Depends on: None
- Priority: P0
- Estimated effort: 20 minutes

## CONTEXT
- Working directory: `src/components/ui/`
- Key files to create: `Carousel.tsx`
- Dependencies: `framer-motion`, `lucide-react` (for chevron arrows), `react` (for hooks).

## TASK
Create a reusable `Carousel.tsx` component that handles an array of image paths with auto-play and manual navigation capabilities.

## SPECIFICATIONS

**1. State & Interval Logic (React Hooks):**
- Use `useState` to track the `currentIndex`.
- Use `useEffect` to create a `setInterval` that advances the index every 5000ms (5 seconds).
- **CRITICAL:** Return a cleanup function (`clearInterval`) inside the `useEffect` to prevent memory leaks.
- Pause auto-play when the user hovers over the carousel (optional but highly recommended for UX).

**2. Visual & Design System:**
- Container: Use the standard card shape with `rounded-[12px]` (`shape-card`) and overflow-hidden. Apply the standard soft shadow `shadow-sm` or custom `0 0 0.5px rgba(0,0,0,0.14), 0 1px 1px rgba(0,0,0,0.24)`.
- Navigation Arrows: Overlay left/right translucent buttons using Lucide icons.
- Indicator Dots: Positioned at the bottom center. 
  - Active dot: `bg-accent-green` (`#00754A`).
  - Inactive dot: `bg-white/50` or `bg-surface`.

**3. Animation (Framer Motion):**
- Use `<AnimatePresence>` and `<motion.img>` (or `<motion.div>`) to fade (`opacity: 0` to `opacity: 1`) or slide images when the index changes.

## ACCEPTANCE CRITERIA
Given: The `Carousel` component logic.
When: 5 seconds pass without user interaction.
Then: The `currentIndex` must automatically increment, looping back to 0 at the end.

Given: The `Carousel` component.
When: The component unmounts.
Then: The interval must be cleared (no memory leak warnings in console).
